# Общие положения

## Цель практического курса

Практические занятия направлены на формирование навыков разработки кроссплатформенных мобильных приложений на C# и .NET MAUI.

В ходе курса студент последовательно создаёт приложение **Task Manager**, поддерживающее:

- создание задач;
- редактирование задач;
- удаление задач;
- отметку выполнения;
- навигацию между экранами;
- поиск и фильтрацию;
- локальное хранение данных;
- работу с REST API;
- обработку ошибок;
- асинхронные операции;
- архитектуру MVVM;
- Dependency Injection.

## Ход работы

### Шаг 1. Создание проекта

В Rider:

1. Создать новый проект.
2. Выбрать шаблон `.NET MAUI App`.
3. Указать имя проекта:

```text
TaskManager
```

4. Выбрать папку проекта.
5. Создать приложение.

### Шаг 2. Изучение структуры

Найти:

```text
App.xaml
App.xaml.cs
AppShell.xaml
MainPage.xaml
MainPage.xaml.cs
MauiProgram.cs
```

Ответить письменно:

1. Для чего нужен `App.xaml`?
2. Что находится в `MauiProgram.cs`?
3. Для чего используется `AppShell`?
4. Чем отличаются `.xaml` и `.xaml.cs`?

### Шаг 3. Изменение интерфейса

Открыть `MainPage.xaml`.

Заменить стандартный текст на:

```xml
<Label
    Text="Task Manager"
    FontSize="32"
    HorizontalOptions="Center" />

<Label
    Text="Практическая работа №1"
    HorizontalOptions="Center" />

<Button
    Text="Начать работу"
    HorizontalOptions="Center" />
```

Элементы необходимо расположить внутри подходящего layout-контейнера.

### Шаг 4. Первый обработчик

Создать обработчик нажатия на кнопку.

При нажатии приложение должно вывести сообщение:

```text
Приложение готово к работе!
```

### Шаг 5. Запуск

Запустить приложение.

Проверить:

- приложение стартует;
- элементы видны;
- кнопка реагирует;
- ошибок в Debug Output нет.

### Шаг 6. Git

Создать первый commit:

```text
Initial MAUI project
```
